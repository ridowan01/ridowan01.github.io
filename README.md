This portfolio showcases my work as a **Computer Science & Engineering undergraduate at RUET**, with interests in:

## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/ridowan01/ridowan01.github.io.git
```

Move into the project directory:

```bash
cd ridowan01.github.io
```

Run the project using a local web server such as **VS Code Live Server**, because the site loads HTML components dynamically using `fetch()`.
